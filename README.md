# Projetos

Repositório criado para reunir projetos, automações, experimentos e soluções desenvolvidas ao longo da minha jornada na programação.

Os projetos apresentam diferentes aplicações de **Python, automação de tarefas, Selenium, integração com APIs, manipulação de dados, chatbots e automação de sistemas desktop/web**.

## Projetos

### CensoCidades

Aplicação em Python para consulta de dados populacionais de municípios brasileiros utilizando a **API do IBGE**.

O projeto recebe códigos de municípios, consulta os dados diretamente na API e apresenta informações como nome da cidade e população.

**Tecnologias:** Python, Requests, API REST, IBGE.

---

### Controle de Contatos - GetNinjas

Projeto de automação voltado ao **controle e gerenciamento de contatos**, desenvolvido para atender uma demanda prática de trabalho.

A solução utiliza automação para facilitar tarefas repetitivas relacionadas ao gerenciamento de informações.

**Tecnologias:** Python, automação e processamento de dados.

---

### EzCad2 - GetNinjas

Projeto de automação e integração com o **EZCAD2**, software utilizado para controle de equipamentos de gravação a laser.

Inclui scripts em Python, automação de processos e recursos relacionados à comunicação e operação do software.

**Tecnologias:** Python, automação desktop, EZCAD2 e integração com software externo.

---

### Odonto Python

Projeto experimental desenvolvido em Python relacionado à área odontológica.

Foi utilizado como estudo para desenvolvimento de uma aplicação voltada ao gerenciamento de informações e processos de uma aplicação odontológica.

**Tecnologia:** Python.

---

### Poker - GetNinjas

Projeto de automação desenvolvido para trabalhar com uma interface de mesa de poker.

O projeto contém scripts Python, arquivos JSON de configuração e presets utilizados para automatizar e controlar elementos da aplicação.

**Tecnologias:** Python, automação e JSON.

---

### Projeto Bot Tabela

Automação desenvolvida para manipulação e processamento de dados apresentados em tabelas.

O projeto utiliza Python e automação de navegador para executar tarefas repetitivas e trabalhar com informações estruturadas.

**Tecnologias:** Python, Selenium, automação web e JSON.

---

### Projeto Chatbot

Projeto experimental de **chatbot em Python**, incluindo mecanismos de treinamento e processamento de conversas.

O repositório contém scripts para o bot, processamento de conversas, arquivos de treinamento e integração com navegador, além de uma base SQLite.

**Tecnologias:** Python, chatbot, Selenium, SQLite e processamento de texto.

---

### SEEDUC - Marceli

Projeto de automação desenvolvido para trabalhar com **planilhas e processos administrativos da SEEDUC-RJ**.

Inclui macros VBA para copiar, organizar e manipular dados em planilhas, além de recursos de automação utilizando Selenium.

**Tecnologias:** Excel, VBA, Python/Selenium e automação de processos.

---

### Spam Bot - GetNinjas

Projeto experimental de automação desenvolvido em Python para execução automatizada de tarefas repetitivas.

O projeto utiliza Selenium e arquivos de dados para controlar o comportamento da automação.

**Tecnologias:** Python, Selenium, automação web e JSON.
